QIRA'AH AI — STARTER PROTOTYPE

What this version does:
- Selects any Al-Fatihah ayah (1–7).
- Shows Arabic text and a simple English meaning.
- Uses the browser's Speech Recognition when supported.
- Recognizes spoken Arabic and compares recognized words with the selected ayah.
- Shows a simple word-match score and highlights missing/different/extra words.
- Includes a small chatbot panel.

What it DOES NOT claim:
- It does not reliably detect all Tajweed mistakes.
- It does not reliably detect makharij/pronunciation errors.
- It does not certify Quranic grammar or recitation.
- Speech recognition can make mistakes.

How to run:
1. Keep index.html on your computer.
2. Open index.html in Google Chrome or Microsoft Edge.
3. Allow microphone permission.
4. Select an ayah and press Start Reciting.
5. Speak the ayah in Arabic.

Next development stages:

This is deliberately a prototype: it is better to show a small feature that genuinely works than claim an AI can detect every Quranic error before it can.
